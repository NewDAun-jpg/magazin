Учебный магазин
    
    Простой, но готовый к использованию веб-сайт электронной коммерции,
    созданный на Django. Включает в себя списки товаров, категории, аутентификацию, 
    корзину покупок (добавление/обновление/удаление)

Этот проект был создан для практики и демонстрации:

    Django ORM для управления продуктами и категориями
    Аутентификация пользователей,и редактирования профиля, и обработка сессий
    Функционал корзины с функциями добавления/обновления/удаления товаров.

Особенности Каталог продукции и категории

    Аутентификация пользователя (регистрация, вход, выход)
    Корзина покупок с возможностью обновления количества и удаления товаров.
    PostgreSQL
